# Wildlife Dev Bridge Workflow

The provider is part of the owner-controlled `Herds.dll`; no adapter DLL is distributed. Build the gameplay module, regenerate the loaded-module manifest, and validate its exact identity, MVID, length, and hash. Discover the live bridge and query `Lan.Wildlife` context before testing. For a coordinator-owned sandbox request `restart request --agent-id <id> --package-id Lan.Wildlife --readiness game --save-policy none`; attached/live processes require a person or external orchestrator. A Herds change requires fresh context and discarded leases, cursors, handles, and cached state after restart.
